# Q3 읽기 노트 — 팀(base) vs 혼자(baseline), 반복 0

비교표: `한국_배터리_3사_LG에너지솔루션_삼__r0.md`
팀 원본: `output/runs/0923-214826_base/` · 혼자 원본: `output/runs/0923-220131_baseline/`

| | 팀 | 혼자 |
|---|---|---|
| 근거율 | 0.63 | 0.50 |
| 호출 · 시간 | 5회 · 101초 | 2회 · 51초 |
| 읽은 문서 | 9건 (절당 3) | 9건 |
| 실제 인용된 문서 | LG Chem · Samsung SDI · SK Innovation | 같음 |

## 짚을 점 (사실만 — 판단은 아래 칸에)

1. **목차 축이 다르다**
   - 팀: 회사별 3절 (LG / 삼성 / SK) — 절마다 한 회사만
   - 혼자: 비교 축 5절 (사업 구조 / 시장 위치 / 차세대 기술 / 고객사 / 법적 분쟁) — 절마다 세 회사를 견줌
   - 질문은 "전략 **차이**는?" 팀 보고서엔 회사끼리 비교하는 문장이 거의 없다. 조사관은 자기 회사만 보고 편집자는 본문을 안 보니 비교할 사람이 없는 구조 (격리의 대가)

2. **실제로 쓴 자료는 사실상 같다**
   - 둘 다 인용이 세 회사 문서에서만 나온다
   - 팀이 추가로 읽은 Hyundai · Kia · Grid storage · LFP 문서는 인용되지 않았다

3. **혼자 쪽에만 있는 핵심 사실: LG vs SK 소송**
   - 2019년 ITC 영업비밀 소송, SK가 LG에 18억 달러 지급 합의 — 원문(SK Innovation) 확인함
   - 팀의 SK 절도 같은 문서를 읽었지만 안 썼다. 절 제목이 "에너지 다각화 전략"인데 본문에 다각화 내용이 없다 → 코디네이터가 150자 카드만 보고 제목을 추측으로 지은 듯

4. **근거율 차이(0.63 vs 0.50)의 정체**
   - 혼자 쪽의 인용 없는 문장은 대부분 해석: "선제적 투자로 평가된다", "기술 경쟁이 치열한지를 보여준다", "성공이 제한적이었다"
   - "성공이 제한적이었다"는 원문에 없는 평가

5. **지표가 못 잡고 사람만 잡은 오류**
   - 혼자: "LG Chem은 **기술 라이센싱**과 소재 공급 방식으로 협력" «LG Chem» → 조사관이 읽은 범위(앞 6,000자)에 "licens", "partner" 없음 = 인용은 붙었는데 내용이 다른 **3등급 환각**
   - 팀: "**LG에너지솔루션은** 1999년에 한국 최초의 리튬이온 배터리 개발" → 원문 주어는 LG Chem. LG에너지솔루션은 2020년 설립 = **주체 혼동**

## 판단을 돕는 질문

1. 받는 사람이 **진입 전략을 세우는 사람**이라면 — 회사별 정리(팀)와 비교 축(혼자) 중 어느 쪽이 더 쓸모 있나?
2. 팀은 근거율이 높다. 혼자는 핵심 사실(소송)이 하나 더 있고 환각도 한 문장 있다. 어떻게 저울질할까?
3. 팀 보고서에 비교가 빠진 문제는 어디를 고치면 될까? (힌트: 목차 짜는 방식, 또는 종합 단계)

## 내 판단

- 보고서라면 혼자 쓴 쪽의 비교 내용이 무조건 들어가야 한다
- 고칠 방향: 조사관 내용은 그대로 쓰고, 편집자가 그걸 보고 판단해서 표 같은 양식으로 정리
- 근거율 vs 핵심 사실 · 환각의 저울질: 판단하기에 정보가 부족하다
- 팀의 근거 없는 문장이 궁금해서 추적 → 11개 중 6개가 지표 버그(제목 줄 5, "Inc." 분리 1), 진짜는 2개
